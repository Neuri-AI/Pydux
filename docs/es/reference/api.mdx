# Referencia de la API

Esta referencia describe la API pública de PyDux implementada por el paquete.

## `Action`

```python
Action(type: str, payload: Any = None, meta: dict[str, Any] = {})
```

Un objeto inmutable de transición de estado.

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `type` | `str` | requerido | Un tipo de action no vacío, convencionalmente `slice/action`. |
| `payload` | `Any` | `None` | Datos consumidos por un reducer. |
| `meta` | `dict[str, Any]` | `{}` | Metadatos ajenos al estado, como una fuente o un ID de correlación. |

Un `type` vacío o que no sea string lanza `ValueError`.

## `create_slice`

```python
create_slice(name, initial_state, reducers, extra_reducers=None) -> Slice
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| `name` | `str` | Namespace no vacío requerido para los tipos de actions generados. |
| `initial_state` | `Any` | Valor inicial de la rama; se realiza una copia profunda antes de la mutación del reducer. |
| `reducers` | `dict[str, Callable[[state, action], Any]]` | Reducers locales indexados por el nombre corto de la action. |
| `extra_reducers` | `dict[str, Callable[[state, action], Any]] \| None` | Reducers indexados por el tipo completo de una action externa. |

Un reducer recibe un draft mutable y una `Action`. Devuelve `None` después de modificar el draft, o devuelve un estado de reemplazo completo.

```python
todos = create_slice(
    name="todos",
    initial_state=[],
    reducers={
        "add": lambda state, action: state.append(action.payload),
        "clear": lambda state, action: [],
    },
)

todos.actions.add({"title": "Write docs"})  # Action(type="todos/add", ...)
```

### `Slice`

| Miembro | Tipo | Descripción |
| --- | --- | --- |
| `name` | `str` | Namespace proporcionado a `create_slice`. |
| `initial_state` | `Any` | Definición original del estado inicial. |
| `actions` | `ActionNamespace` | Valores `ActionCreator` generados con acceso mediante punto. |
| `reducer` | `Callable[[state, action], Any]` | Reducer compatible con `configure_store`. |

Las actions desconocidas dejan sin cambios el objeto slice. Acceder a una action generada inexistente lanza `AttributeError`.

## `configure_store`

```python
configure_store(
    reducer,
    preloaded_state=None,
    middleware=None,
    devtools=True,
    inspector_auto_start=True,
    inspector_host="127.0.0.1",
    inspector_port=8765,
    inspector_log=True,
) -> Store
```

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `reducer` | `Reducer` or `dict[str, Reducer \| Slice]` | requerido | Reducer raíz o reducers/slices de ramas con nombre. |
| `preloaded_state` | `Any \| None` | `None` | Estado inicial; las keys proporcionadas en el mapping reemplazan los valores predeterminados de los slices. |
| `middleware` | `Sequence[Middleware] \| None` | `None` | Middleware añadido después del middleware de thunks integrado. |
| `devtools` | `bool \| PyDuxDevTools` | `True` | Tracker integrado, un tracker personalizado o `False`. |
| `inspector_auto_start` | `bool` | `True` | Inicia el inspector web con DevTools. |
| `inspector_host` / `inspector_port` | `str` / `int` | localhost / 8765 | Destino de binding del inspector; si el puerto está ocupado, se utiliza un puerto libre. |
| `inspector_log` | `bool` | `True` | Imprime la URL de inicio. |

Los thunks siempre están habilitados. DevTools adjunta `store.devtools`; un inicio automático exitoso adjunta `store.inspector`.

## `Store`

| Método | Firma | Comportamiento |
| --- | --- | --- |
| `get_state` | `() -> TState` | Devuelve el estado raíz. No lo modifiques. |
| `dispatch` | `(action: Action \| Callable) -> Any` | Ejecuta la cadena de middleware y devuelve su resultado. |
| `select` | `(selector, listener, equality_fn=None, fire_immediately=False) -> unsubscribe` | Añade una suscripción selectiva. |
| `subscribe` | `(listener) -> unsubscribe` | Añade una suscripción a todo el store después de cada dispatch. |

`select` evalúa su selector al suscribirse. Con `fire_immediately=True`, llama al listener con ese valor. Después, llama al listener únicamente si `equality_fn(previous, current)` es false; `shallow_equal` es el valor predeterminado.

Calling `unsubscribe()` more than once is safe. Listener failures are logged and isolated. A non-`Action` directly dispatched to `Store` raises `TipoError`; dispatching from inside a reducer raises `RuntimeError`.

## Selectores y comparaciones

```python
create_selector(*input_selectors, result_function, equality_fn=shallow_equal) -> MemoizedSelector
```

At least one input selector and one result function are requerido, otherwise `ValueError` is raised.

| Miembro | Descripción |
| --- | --- |
| `recomputations` | Número de veces que se ejecutó la función de resultado. |
| `reset_recomputations()` | Restablece el contador sin borrar el resultado almacenado en caché. |

| Helper | Comportamiento exacto |
| --- | --- |
| `is_identical(a, b)` | `a is b`. |
| `shallow_equal(a, b)` | Identidad, después valores de nivel superior de dict/list/tuple y, finalmente, igualdad normal. |
| `deep_equal(a, b)` | Igualdad recursiva mediante `a == b`. |

## Thunks asíncronos y middleware

```python
create_async_thunk(type_prefix, payload_creator) -> AsyncThunk
create_thunk_middleware(extra_argument=None) -> Middleware
```

Despachar un `AsyncThunk` ejecuta `payload_creator(*args, **kwargs)` y emite `type_prefix/pending`, después `fulfilled` con su resultado, o `rejected` con `str(exception)` y `meta={"error": True}`. Los awaitables se resuelven. Los errores se vuelven a lanzar después de `rejected`; los callables de thunk reciben `(dispatch, get_state, extra_argument)`.

## DevTools e inspector

```python
PyDuxDevTools(max_history=100)
start_inspector(store, host="127.0.0.1", port=8765,
                auto_reassign_port=True, log_startup=True) -> PyDuxInspectorServer
```

`history` devuelve copias de `ActionTrace` con `index`, `action`, `prev_state`, `next_state`, `timestamp`, `duration_ms` y `changed_paths`.

| Método | Comportamiento |
| --- | --- |
| `undo()` / `redo()` | Navega por los estados registrados si están disponibles. |
| `jump_to_state(index)` | Restaura un estado de trace válido. |
| `subscribe_traces(listener)` | Devuelve una función de cancelación de suscripción para traces. |
| `export_trace_json()` | Exporta los metadatos de los traces como JSON. |

Un inspector expone `host`, `port`, `base_url`, `start()` y `stop()`. `start_inspector` reutiliza un inspector existente y lanza `ValueError` sin DevTools.

## Adaptadores de UI y Qyro

```python
ReactiveBinding(store, selector, target, equality_fn=None, bridge=None)
connect(store, map_state_to_props=None, bridge=None)
Reactive.bind_selector(store, selector, on_change, equality_fn=None) -> unsubscribe
connect_qyro(store, selectors) -> class decorator
```

`ReactiveBinding` se suscribe inmediatamente y programa `target(value)` mediante su bridge; `dispose()` cancela la suscripción. `connect` asigna las entradas de `map_state_to_props(state)` a atributos de la instancia y después llama al `on_props_changed()` opcional; almacena las funciones de cancelación de suscripción en `_pydux_unsubscribers`.

`Reactive.bind_selector` retrasa su primer callback hasta el tick de UI de Qt, Tkinter o Kivy, realiza seguimiento de cada función de cancelación de suscripción y las libera en `component_will_unmount`. `connect_qyro` acepta `{attribute_name: selector}`, escribe valores en los atributos del componente, llama al `on_state_change(props_copy)` opcional y realiza la limpieza al desmontarse.
