# `configure_store`

```python
configure_store(
    reducer,
    preloaded_state=None,
    middleware=None,
    devtools=True,
    inspector_auto_start=True,
    inspector_host="127.0.0.1",
    inspector_port=8765,
    inspector_log=True,
) -> Store
```

Crea un store con middleware de thunks. Acepta un reducer raíz o un mapping de nombres de slices a instancias de `Slice` o funciones reducer.

| Parámetro | Descripción |
| --- | --- |
| `reducer` | Reducer raíz o mapping de nombres a reducers/slices. |
| `preloaded_state` | Sobrescritura opcional del estado inicial. Con mappings de reducers, las keys proporcionadas reemplazan el estado inicial calculado del slice. |
| `middleware` | Middleware adicional, después del middleware de thunks integrado. |
| `devtools` | `True` para los DevTools integrados, una instancia de `PyDuxDevTools` o `False`. |
| `inspector_auto_start` | Inicia el inspector web cuando DevTools están habilitados. |
| `inspector_host` | Host de binding del inspector. |
| `inspector_port` | Puerto preferido del inspector; si está ocupado, se elige un puerto libre. |
| `inspector_log` | Imprime información de inicio del inspector. |

## Ejemplos

```python
# A reducer mapping
store = configure_store({"counter": counter_slice}, devtools=False)

# A root reducer
store = configure_store(root_reducer, preloaded_state={"counter": {"value": 0}})
```

Cuando DevTools están habilitados, el store expone `store.devtools`. Cuando el inspector se inicia correctamente, también expone `store.inspector`.
