# Selectores y suscripciones

Un selector es una función que transforma el estado completo en el valor que necesita un consumidor.

```python
select_user_name = lambda state: state["user"]["name"]
```

Suscríbete con `store.select(...)`. Devuelve una función `unsubscribe`.

```python
unsubscribe = store.select(
    selector=select_user_name,
    listener=lambda name: label.setText(name),
    fire_immediately=True,
)
unsubscribe()
```

## Selectores derivados y memoizados

`create_selector` compone selectores de entrada y almacena en caché el cálculo anterior.

```python
from pydux import create_selector

select_first_name = lambda state: state["user"]["first_name"]
select_last_name = lambda state: state["user"]["last_name"]

select_full_name = create_selector(
    select_first_name,
    select_last_name,
    lambda first, last: f"{first} {last}",
)
```

Si las entradas seleccionadas no han cambiado, el combinador no vuelve a ejecutarse.

## Funciones de igualdad

`store.select` utiliza `shallow_equal` de forma predeterminada. Proporciona una función de igualdad cuando tu selector cree un contenedor o cuando la identidad sea el contrato correcto.

| Helper | Úsalo cuando |
| --- | --- |
| `is_identical` | La misma instancia exacta del objeto indique que no hay cambios. |
| `shallow_equal` | Deban compararse los valores de nivel superior de dicts, listas o tuplas. |
| `deep_equal` | Se necesite igualdad estructural anidada; úsalo con moderación. |

```python
from pydux import shallow_equal

store.select(
    lambda state: {"name": state["user"]["name"], "count": state["counter"]["value"]},
    update_header,
    equality_fn=shallow_equal,
)
```

<Warning>
  No modifiques el objeto devuelto por `store.get_state()`. Los reducers deben ser el único código que cambie el estado compartido.
</Warning>
