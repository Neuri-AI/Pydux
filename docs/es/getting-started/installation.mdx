# Instalación

PyDux es compatible con Python `>=3.10,<3.16`. El core utiliza únicamente la biblioteca estándar;
los paquetes de frameworks son extras opcionales.

## Paquete core

<CodeGroup>
```bash pip
pip install pydux
```

```bash Poetry
poetry add pydux
```
</CodeGroup>

Para un checkout local, instala en modo editable:

```bash
pip install -e .
```

## Extras de frameworks

Instala únicamente el stack utilizado por la aplicación.

| Integración | pip | Poetry |
| --- | --- | --- |
| PySide6 | `pip install "pydux[pyside6]"` | `poetry add pydux -E pyside6` |
| PyQt6 | `pip install "pydux[pyqt6]"` | `poetry add pydux -E pyqt6` |
| PySide2 | `pip install "pydux[pyside2]"` | `poetry add pydux -E pyside2` |
| PyQt5 | `pip install "pydux[pyqt5]"` | `poetry add pydux -E pyqt5` |
| Kivy | `pip install "pydux[kivy]"` | `poetry add pydux -E kivy` |
| Qyro + PySide6 | `pip install "pydux[qyro,pyside6]"` | `poetry add pydux -E qyro -E pyside6` |

Tkinter se incluye con la mayoría de las distribuciones de CPython y no requiere ningún extra de PyDux.

<Note>
  `pydux[all]` instala todas las integraciones opcionales. Es útil para desarrollo
  y pruebas de compatibilidad, pero las aplicaciones normalmente deberían instalar únicamente su
  framework de UI seleccionado.
</Note>

## Previsualiza esta documentación localmente

Este directorio es una raíz de documentación de Mintlify. Instala Mintlify CLI y luego
ejecútalo desde `docs/`:

```bash
npm install -g mint
cd docs
mint dev
```

Mintlify servirá una vista previa local y validará la navegación de `docs.json` y las
páginas MDX mientras las editas.
